# Milestone 6 Review (cards, grading, FSRS, weekly news quiz, reminder) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-fast:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Daily reviews on the phone, offline included: cards from sources, primers and the week's briefs; typed or spoken answers graded by Haiku (self-grade on timeout, error or offline); FSRS scheduling on the phone with the never-push-later rule; review ahead and practice by topic or source; a weekly news quiz; one local reminder a day.

**Architecture:**
- DB (`0007_review`): `cards` gain FSRS columns, nullable `source_id`/`artifact_id`, `topic_primer_id`, `brief_id`, `expires_at` and an exactly-one-origin CHECK; `sources.cards_off`; new tables `reviews` (append-only log) and `card_preferences`. Shared card helpers live in `archie_db.card_rows`.
- `packages/archie-llm`: the model client (`llm.complete`, prices, cost records) and the Groq/OpenAI transcription requests move out of the worker so the API can call them.
- API: four push actions (`review_card`, `drop_card`, `set_cards_off`, `request_news_quiz`), the pull carries the new card and source columns, and three synchronous routes under `/review` (grade, transcribe, care).
- Worker: primers and topic primers also write 2–3 `foundation` cards; analyze/primer/topic primer read the user's last 20 card preferences; analyze skips cards when `cards_off`; new `news_quiz` job.
- App: drizzle migration 0007 (re-pull), sync of the new columns, optimistic actions, a phone-only review log; pure review logic in `app/src/review/` (`ts-fsrs` scheduling, session building, eligibility, counts, reminder plan); screens: Today review card + quiz row, the session (answer, grade, self-grade, care, drop, mic), Done, Review tab, topic practice, item page "Cards from this", item menu, Settings → Review; local notifications.

**Tech Stack:** as M5, plus app packages `ts-fsrs` (v5), `expo-notifications`, `expo-audio` (installed once in Task 3), API dependency `python-multipart` (Task 7), and the new workspace package `archie-llm` (Task 2).

**Spec:** `docs/superpowers/specs/2026-11-05-m6-review-design.md` (source of truth; where the mocks `2026-11-05-m6-review-mocks.html` disagree, the spec wins, e.g. voice goes through Groq, not on-device dictation, and there is no shake-to-undo). Grading prompt: `spikes/card_grading/README.md` ("The prompt as tested", 1-shot variant). UX rules: `docs/superpowers/specs/2026-10-29-ux-and-brand-design.md`.

## Global Constraints

- **Python style:** `AGENTS.md` house style (module-qualified imports as the repo does them, e.g. `from archie_db import card_rows, changes, models` then `card_rows.retire_cards(...)`; classes/`typing` by name; full typing with `X | None`; `StrEnum`s for compared strings; dataclasses over tuples of >2; named parameters; guard clauses; blank-line paragraphs past ~8 lines; why-comments; docstrings on public functions/classes).
- **Handler contract** (`services/worker/archie_worker/loop.py` docstring): read into locals and `db.commit()` before any outside call; then `changes.lock_user_writes`, re-read the rows, skip if deleted/removed, write. **The API's `/review/grade` and `/review/cards/{id}/care` routes follow the same rule**: read the card into locals, `db.commit()`, call the model, then (care only) lock and write.
- **Action contract:** every push action handler has the signature `(db: orm.Session, *, user: models.User, payload: dict[str, object]) -> str | None` (rejection reason or None) and runs under the batch's user lock inside a savepoint. **A handler validates everything before its first write**: returning a reason does *not* roll back earlier writes. Every changed synced row gets a fresh `change_seq` (sources via `changes.touch`, cards by setting `change_seq = changes.next_change_seq()` and `updated_at = func.now()`).
- **Wire payloads** (snake_case; `id` is always the row the action changes, which the phone's "keep the local copy while an action is unsent" rule in `transport.applyPage` relies on; the spec's `card_id`/`source_id` are sent as `id`):

## Decisions made while planning

1. **Action payloads use `id` for the changed row** (card for `review_card`/`drop_card`, source for `set_cards_off`), as every M4/M5 action does, so an unsent action keeps the phone's local card/source when a pull lands. `review_card` also carries `state_before`, which the `reviews` table stores.
2. **Which state wins on the server:** `review_card` always logs the review; it writes `state_after` to the card unless the server already has a review of that card with a later `reviewed_at`. (Comparing against the card's own `last_review_at` would wrongly drop a not-due got_it, whose unchanged state keeps an older `last_review_at`.) "I actually knew it" is a new review with `reviewed_at` = the moment it was tapped, so it always wins over the review it replaces.
3. **FSRS runs long-term only** (`ts-fsrs` with `enable_short_term: false`, `enable_fuzz: false`): a session shows each card once, so the 1 min / 10 min learning steps would never be honored, and the server has no column for them. Fuzz off keeps the never-push-later tests deterministic.
4. **Partly/missed on a card that wasn't due** apply FSRS but the result's `due_at` is clamped to the old `due_at` (FSRS Hard on an early review can land later than the current due date, which would break "never push later").
5. **Quiz cards are "answered" when `last_review_at` is set.** `applyGrade` on a quiz card returns its state with only `last_review_at` = now; no new column, and a re-pull keeps them answered.
6. **Eligibility:** source cards (non-foundation, with `source_id`) need the source `consumed`; foundation cards with `source_id` need `sources.primer_opened_at`; foundation cards with `topic_primer_id` need `topic_primers.opened_at` and a live (not removed, not merged) topic; quiz cards are only in quiz mode; any other origin is never reviewable.
7. **Foundation cards from a source primer** keep `source_id` and set `artifact_id` to the primer artifact; a newer primer retires the source's live foundation cards from other artifacts. **Analyze's own re-run now retires only non-foundation cards** (today it retires every card of the source whose artifact isn't the current summary, which would delete foundation cards). Topic-primer foundation cards set `topic_primer_id` only; a new topic primer version retires those of the topic's older versions.
8. **Foundation cards ride at the end of the primer's markdown** in a `<foundation_cards>[…]</foundation_cards>` JSON block that the worker strips off, rather than a JSON-schema response: the recorded primer responses in the five `pipeline_*` API cassettes (two of them podcast recordings that can't be re-made reliably) then still replay, yielding no foundation cards. Only `primer_greatwork` and `topic_primer_fed` are re-recorded. A missing or malformed block costs the cards, never the primer.
9. **`set_cards_off` off retires all of the source's live cards, foundation cards included,** and primers skip foundation cards while `cards_off`. Turning cards back on (`off: false`) clears the flag and re-queues `analyze` only (as the spec says); the source's foundation cards return the next time its primer is written. `go_deeper` also clears `cards_off`, since "Make review cards" on an inbox item goes through it.
10. **"Make review cards"** (menu) shows when the source is ready and either cards are off or it has no live cards; on an inbox/briefed item it runs `go_deeper` (as today), otherwise `set_cards_off {off: false}`. **Remove on the item page and Drop in review both send `drop_card`** (both save a "not this" preference).
11. **`request_news_quiz` is idempotent per week through the jobs table:** it enqueues `news_quiz` (payload `{user_id, week_start}`) unless a non-failed `news_quiz` job with that `week_start` exists for the user, or no brief was Done in the last 7 days; either way it is applied (never rejected), since the phone sends it on every Sunday Today open. The phone also sends it at most once per app run per week.
12. **One-card sessions** use an extra mode `card` (`/review/session?mode=card&id=<card id>`), opened from an item page row. Rows of cards that aren't reviewable yet ("After you finish") aren't tappable.
13. **Transcription cost** is recorded from the phone's `duration_ms` (the recorder knows it; OpenAI's response has no duration). Audio over 125 s or 5 MB is refused with 413.
14. **Session order ties:** within a group the most overdue first, where a new card's "due" is its `created_at`; then by id. Quiz sessions are in `created_at` order.
15. **"I actually knew it"** shows under Partly and Missed verdicts (under Got it it would do nothing). The Done screen's "N cards" counts graded cards; Dropped is its own tally row.
16. **The quiz kicker** is "This week · News" in the neutral (Other) colour, since quiz cards have no domain. A source card without a domain uses Other.
17. **Reminder permission** is asked the first time a reminder would be scheduled after a finished session or when the Settings toggle is turned on, never at launch. Settings live in a phone-only `review_settings` row (defaults when absent). Sign-out cancels scheduled reminders and wipes the phone's review log.
18. **A grading or care call for a non-whitelisted user is 403**; the phone treats any grading failure as "Couldn't grade this one".

```python
    naming that summary or primer version), a topic primer (foundation cards) or a brief (quiz cards).

        sqlalchemy.CheckConstraint(CARD_ORIGIN_CHECK, name="ck_cards_one_origin"),
```

```python
"""Card rows shared by the API and the worker: ownership, retiring cards, the user's card preferences, done briefs.

Every function that writes expects the caller to hold `changes.lock_user_writes` for the user.
"""

from __future__ import annotations

import datetime
import uuid
from dataclasses import dataclass

import sqlalchemy
import sqlalchemy.orm

from archie_db import changes, models

MAX_PREFERENCE_NOTES = 20
QUIZ_LIFETIME = datetime.timedelta(days=7)
QUIZ_BRIEF_WINDOW = datetime.timedelta(days=7)
# The `news_quiz` job payload key naming the week (the phone's local Sunday, "YYYY-MM-DD") it was asked for.
WEEK_START_KEY = "week_start"


@dataclass(frozen=True)
class PreferenceNote:
    """One thing the user told Archie about cards: what they care about, or the question of a card they dropped."""

    kind: models.CardPreferenceKind
    note: str


def owned_live_card(db: sqlalchemy.orm.Session, *, user_id: int, card_id: uuid.UUID) -> models.Card | None:
    """The user's card with this id; another user's or a deleted one is treated as missing."""
    card = db.get(models.Card, card_id)
    if card is None or card.user_id != user_id or card.deleted_at is not None:
        return None
    return card


def retire_cards(db: sqlalchemy.orm.Session, *criteria: sqlalchemy.ColumnElement[bool]) -> None:
    """Soft-delete the live cards matching `criteria`, each with a fresh change position so phones drop them."""
    db.execute(
        sqlalchemy.update(models.Card)
        .where(models.Card.deleted_at.is_(None), *criteria)
        .values(
            deleted_at=sqlalchemy.func.now(),
            updated_at=sqlalchemy.func.now(),
            change_seq=changes.next_change_seq(),
        )
    )


def recent_preferences(
    db: sqlalchemy.orm.Session, *, user_id: int, limit: int = MAX_PREFERENCE_NOTES
) -> list[PreferenceNote]:
    """The user's latest card preferences, newest first."""
    rows = db.scalars(
        sqlalchemy.select(models.CardPreference)
        .where(models.CardPreference.user_id == user_id)
        .order_by(models.CardPreference.created_at.desc(), models.CardPreference.id.desc())
        .limit(limit)
    )
    return [PreferenceNote(kind=models.CardPreferenceKind(row.kind), note=row.note) for row in rows]


def recently_done_briefs(
    db: sqlalchemy.orm.Session, *, user_id: int, window: datetime.timedelta = QUIZ_BRIEF_WINDOW
) -> list[models.Brief]:
    """The user's briefs marked Done within `window` of now (the database's clock), newest first."""
    return list(
        db.scalars(
            sqlalchemy.select(models.Brief)
            .where(
                models.Brief.user_id == user_id,
                models.Brief.status == models.BriefStatus.DONE.value,
                models.Brief.done_at >= sqlalchemy.func.now() - window,
            )
            .order_by(models.Brief.done_at.desc())
        )
    )
```

```ts
/** Logs a graded answer and schedules the card at once (offline too); the server keeps the latest review's state. */
export function reviewCard(db: AppDb, input: ReviewInput): string {
  const reviewId = randomUUID();
  const reviewedAt = input.reviewedAt.toISOString();
  db.transaction((tx) => {
    tx.insert(schema.reviews)
      .values({
        id: reviewId,
        cardId: input.cardId,
        grade: input.grade,
        gradedBy: input.gradedBy,
        answer: input.answer,
        missing: input.missing,
        wasDue: input.wasDue ? 1 : 0,
        reviewedAt,
        stateBefore: JSON.stringify(input.stateBefore),
        stateAfter: JSON.stringify(input.stateAfter),
        replacesReviewId: input.replacesReviewId ?? null,
      })
      .run();
    tx.update(schema.cards).set(input.stateAfter).where(eq(schema.cards.id, input.cardId)).run();
    enqueue(tx, "review_card", {
      id: input.cardId,
      review_id: reviewId,
      grade: input.grade,
      graded_by: input.gradedBy,
      answer: input.answer,
      missing: input.missing,
      was_due: input.wasDue,
      reviewed_at: reviewedAt,
      state_before: wireState(input.stateBefore),
      state_after: wireState(input.stateAfter),
      replaces_review_id: input.replacesReviewId ?? null,
    });
  });
  return reviewId;
}

/** Drop (in review) and Remove (on the item page): the card goes, and the server saves a "not this" preference. */
export function dropCard(db: AppDb, cardId: string): void {
  db.transaction((tx) => {
    tx.update(schema.cards).set({ deletedAt: new Date().toISOString() }).where(eq(schema.cards.id, cardId)).run();
    enqueue(tx, "drop_card", { id: cardId });
  });
}

/** "No cards for this" retires the source's cards; turning cards back on re-runs analyze, as the server does. */
export function setCardsOff(db: AppDb, sourceId: string, off: boolean): void {
  db.transaction((tx) => {
    if (off) {
      updateSource(tx, sourceId, { cardsOff: 1 });
      tx.update(schema.cards)
        .set({ deletedAt: new Date().toISOString() })
        .where(and(eq(schema.cards.sourceId, sourceId), isNull(schema.cards.deletedAt)))
        .run();
    } else {
      updateSource(tx, sourceId, { cardsOff: 0, processing: "processing", processingError: null });
    }
    enqueue(tx, "set_cards_off", { id: sourceId, off });
  });
}
```

**`schedule.ts`** (ts-fsrs v5 API; if `npm ls ts-fsrs` shows another major, adapt the four imported names and nothing else):

```ts
import { createEmptyCard, fsrs, generatorParameters, Rating, State, type Card as FsrsCard } from "ts-fsrs";

import type { FsrsFields, FsrsStateName, ReviewGrade } from "./types";

// Long-term only: a session shows each card once, so same-day learning steps would never be honored, and there is no
// column for them. No fuzz, so a grade always schedules the same way (and the tests can say exactly how).
const scheduler = fsrs(generatorParameters({ enable_short_term: false, enable_fuzz: false }));

const RATING_BY_GRADE = { got_it: Rating.Good, partly: Rating.Hard, missed: Rating.Again } as const;
const STATE_BY_NAME: Record<FsrsStateName, State> = {
  new: State.New,
  learning: State.Learning,
  review: State.Review,
  relearning: State.Relearning,
};
const NAME_BY_STATE: Record<State, FsrsStateName> = {
  [State.New]: "new",
  [State.Learning]: "learning",
  [State.Review]: "review",
  [State.Relearning]: "relearning",
};
const DAY_MS = 86_400_000;

/**
 * The card's state after a grade. Extra practice (a card that wasn't due) can only bring a card sooner: got_it leaves
 * it as it was, and partly/missed never move it later than it already was. Quiz cards are never scheduled; the
 * review only marks them answered.
 */
export function applyGrade(
  card: FsrsFields & { kind: string },
  grade: ReviewGrade,
  now: Date,
  wasDue: boolean,
): FsrsFields {
  const before = pickFields(card);
  if (card.kind === "quiz") return { ...before, lastReviewAt: now.toISOString() };
  if (!wasDue && grade === "got_it") return before;

  const after = fromFsrsCard(scheduler.next(toFsrsCard(before, now), now, RATING_BY_GRADE[grade]).card);
  if (wasDue || before.dueAt === null || after.dueAt === null) return after;
  return Date.parse(after.dueAt) > Date.parse(before.dueAt) ? { ...after, dueAt: before.dueAt } : after;
}

/** "I actually knew it": redo the replaced review as a got_it from the state it started from. */
export function knewItState(
  kind: string,
  replaced: { stateBefore: FsrsFields; reviewedAt: string; wasDue: boolean },
): FsrsFields {
  return applyGrade({ ...replaced.stateBefore, kind }, "got_it", new Date(replaced.reviewedAt), replaced.wasDue);
}

function pickFields(card: FsrsFields): FsrsFields {
  const { fsrsState, stability, difficulty, dueAt, lastReviewAt, reps, lapses } = card;
  return { fsrsState, stability, difficulty, dueAt, lastReviewAt, reps, lapses };
}

function toFsrsCard(fields: FsrsFields, now: Date): FsrsCard {
  if (fields.fsrsState === "new" || fields.stability === null || fields.difficulty === null) {
    return { ...createEmptyCard(now), reps: fields.reps, lapses: fields.lapses };
  }

  const due = new Date(fields.dueAt ?? now.toISOString());
  const lastReview = fields.lastReviewAt ? new Date(fields.lastReviewAt) : undefined;
  return {
    due,
    stability: fields.stability,
    difficulty: fields.difficulty,
    elapsed_days: lastReview ? Math.max(0, Math.floor((now.getTime() - lastReview.getTime()) / DAY_MS)) : 0,
    scheduled_days: lastReview ? Math.max(0, Math.round((due.getTime() - lastReview.getTime()) / DAY_MS)) : 0,
    learning_steps: 0,
    reps: fields.reps,
    lapses: fields.lapses,
    state: STATE_BY_NAME[fields.fsrsState],
    last_review: lastReview,
  };
}

function fromFsrsCard(card: FsrsCard): FsrsFields {
  return {
    fsrsState: NAME_BY_STATE[card.state],
    stability: card.stability,
    difficulty: card.difficulty,
    dueAt: card.due.toISOString(),
    lastReviewAt: card.last_review ? card.last_review.toISOString() : null,
    reps: card.reps,
    lapses: card.lapses,
  };
}
```

```ts
  cards: CardRow[];

  topicPrimersById: Map<string, TopicPrimerRow>;
  topicsById: Map<string, TopicRow>;

// Where a card came from. An origin this phone doesn't know yet (a newer server's) is never reviewable here.
export type CardOrigin =
  | { kind: "source"; sourceId: string }
  | { kind: "topicPrimer"; topicPrimerId: string }
  | { kind: "brief"; briefId: string }
  | { kind: "unknown" };

export function cardOrigin(card: CardRow): CardOrigin {
  if (card.sourceId) return { kind: "source", sourceId: card.sourceId };
  if (card.topicPrimerId) return { kind: "topicPrimer", topicPrimerId: card.topicPrimerId };
  if (card.briefId) return { kind: "brief", briefId: card.briefId };
  return { kind: "unknown" };
}

/**
 * A card joins reviews only once you've taken in what it came from: a source's cards once it is consumed, foundation
 * cards once their primer was opened. Quiz cards are answered only in the quiz.
 */
export function isReviewable(card: CardRow, data: ReviewData): boolean {
  if (card.deletedAt !== null) return false;
  const origin = cardOrigin(card);
  switch (origin.kind) {
    case "source": {
      const source = data.sourcesById.get(origin.sourceId);
      if (!source || source.deletedAt !== null) return false;
      return card.kind === "foundation" ? source.primerOpenedAt !== null : source.state === "consumed";
    }
    case "topicPrimer": {
      const primer = data.topicPrimersById.get(origin.topicPrimerId);
      if (!primer || primer.openedAt === null) return false;
      const topic = data.topicsById.get(primer.topicId);
      return topic !== undefined && topic.removedAt === null && topic.mergedIntoId === null;
    }
    case "brief":
    case "unknown":
      return false;
  }
}

export function isOpenQuiz(card: CardRow, now: Date): boolean {
  return (
    card.kind === "quiz" &&
    card.deletedAt === null &&
    card.lastReviewAt === null &&
    card.expiresAt !== null &&
    Date.parse(card.expiresAt) > now.getTime()
  );
}
```

```ts
// Foundations first, then concepts and mechanisms, then rough numbers; anything else last. A placeholder order, to be
// tuned in the eval pass.
const ORDER_GROUP: Record<string, number> = { foundation: 0, concept: 1, mechanism: 1, number: 2 };
const LAST_GROUP = 3;
const DAY_MS = 86_400_000;

export type SessionMode = "due" | "ahead" | "topic" | "source" | "card" | "quiz";
export const SESSION_MODES: readonly SessionMode[] = ["due", "ahead", "topic", "source", "card", "quiz"];
export type SessionCard = { card: CardRow; wasDue: boolean };

export function isDue(card: CardRow, now: Date): boolean {
  return card.fsrsState === "new" || (card.dueAt !== null && Date.parse(card.dueAt) <= now.getTime());
}

// A new card has no due date; it counts as due since it was made.
export function effectiveDue(card: CardRow): number {
  return Date.parse(card.dueAt ?? card.createdAt);
}

export function orderCards(cards: CardRow[]): CardRow[] {
  return [...cards].sort(
    (a, b) =>
      (ORDER_GROUP[a.kind] ?? LAST_GROUP) - (ORDER_GROUP[b.kind] ?? LAST_GROUP) ||
      effectiveDue(a) - effectiveDue(b) ||
      a.id.localeCompare(b.id),
  );
}

/** The cards a session shows, in order, each with whether it was due when the session began. */
export function buildSession(data: ReviewData, mode: SessionMode, id: string | null, now: Date): SessionCard[] {
  if (mode === "quiz") {
    return data.cards
      .filter((card) => isOpenQuiz(card, now))
      .sort((a, b) => Date.parse(a.createdAt) - Date.parse(b.createdAt))
      .map((card) => ({ card, wasDue: true }));
  }

  const reviewable = data.cards.filter((card) => isReviewable(card, data));
  const aheadLimit = now.getTime() + AHEAD_DAYS * DAY_MS;
  const chosen = reviewable.filter((card) => {
    switch (mode) {
      case "due":
        return isDue(card, now);
      case "ahead":
        return !isDue(card, now) && effectiveDue(card) <= aheadLimit;
      case "topic":
        return id !== null && cardTopicId(card, data) === id;
      case "source":
        return id !== null && card.sourceId === id;
      case "card":
        return card.id === id;
    }
  });
  return orderCards(chosen).map((card) => ({ card, wasDue: isDue(card, now) }));
}
```

```ts
/**
 * One reminder a day for the next REMINDER_DAYS days at the reminder time, each only when cards will be due by then.
 * The counts assume no reviews in between; the plan is rebuilt on every foreground and after every session.
 */
export function reminderPlan(data: ReviewData, settings: ReviewSettings, now: Date): PlannedReminder[] {
  if (!settings.reminderEnabled) return [];
  const reviewable = data.cards.filter((card) => isReviewable(card, data));

  return Array.from({ length: REMINDER_DAYS }, (_, offset) => reminderTime(now, offset, settings.reminderMinutes))
    .filter((at) => at.getTime() > now.getTime())
    .map((at) => ({ at, count: reviewable.filter((card) => effectiveDue(card) <= at.getTime()).length }))
    .filter((reminder) => reminder.count > 0)
    .map(({ at, count }) => ({ at, count, body: `${cardsWord(count)} · about ${minutesFor(count)} min` }));
}

function reminderTime(now: Date, dayOffset: number, minutes: number): Date {
  return new Date(now.getFullYear(), now.getMonth(), now.getDate() + dayOffset, Math.floor(minutes / 60), minutes % 60);
}
```

```python
def review_card(db: orm.Session, *, user: models.User, payload: dict[str, object]) -> str | None:
    """Log a graded answer and store the card's new FSRS state, unless a later review of the card already arrived.

    A review id seen before (the same answer sent again under a new action id) is a no-op. The latest review by
    `reviewed_at` decides the card's state, so a late upload from another phone can't roll the schedule back.
    """
    parsed = rows.parse(_ReviewCardPayload, payload)
    if parsed is None:
        return rows.MALFORMED
    card = card_rows.owned_live_card(db, user_id=user.id, card_id=parsed.id)
    if card is None:
        return NO_CARD

    existing = db.get(models.Review, parsed.review_id)
    if existing is not None:
        return None if existing.user_id == user.id and existing.card_id == card.id else _REVIEW_ID_USED
    if parsed.replaces_review_id is not None and not _is_review_of(db, review_id=parsed.replaces_review_id, card=card):
        return _NO_REPLACED_REVIEW

    has_later_review = db.scalar(
        sqlalchemy.select(
            sqlalchemy.exists().where(
                models.Review.card_id == card.id, models.Review.reviewed_at > parsed.reviewed_at
            )
        )
    )
    db.add(
        models.Review(
            id=parsed.review_id,
            user_id=user.id,
            card_id=card.id,
            grade=parsed.grade.value,
            graded_by=parsed.graded_by.value,
            answer=parsed.answer,
            missing=parsed.missing,
            was_due=parsed.was_due,
            reviewed_at=parsed.reviewed_at,
            state_before=parsed.state_before.model_dump(mode="json"),
            state_after=parsed.state_after.model_dump(mode="json"),
            replaces_review_id=parsed.replaces_review_id,
        )
    )
    if not has_later_review:
        _write_state(card, state=parsed.state_after)
    return None


def drop_card(db: orm.Session, *, user: models.User, payload: dict[str, object]) -> str | None:
    """Retire a card the user doesn't want, and remember its question as a "not this" preference."""
    parsed = rows.parse(_CardPayload, payload)
    if parsed is None:
        return rows.MALFORMED
    card = card_rows.owned_live_card(db, user_id=user.id, card_id=parsed.id)
    if card is None:
        return NO_CARD

    card_rows.retire_cards(db, models.Card.id == card.id)
    db.add(
        models.CardPreference(
            user_id=user.id, card_id=card.id, kind=models.CardPreferenceKind.DROP.value, note=card.question
        )
    )
    return None


def set_cards_off(db: orm.Session, *, user: models.User, payload: dict[str, object]) -> str | None:
    """Cards off retires the source's cards (foundation cards too) and stops new ones; cards on re-runs analyze."""
    parsed = rows.parse(_CardsOffPayload, payload)
    if parsed is None:
        return rows.MALFORMED
    source = rows.owned_source(db, user=user, source_id=parsed.id)
    if source is None:
        return rows.NO_SOURCE

    source.cards_off = parsed.off
    changes.touch(source)
    if parsed.off:
        card_rows.retire_cards(db, models.Card.source_id == source.id)
        return None

    # Only a source with text can be analyzed again; one still fetching gets its cards when its analyze runs.
    has_text = pipeline.current_artifact(db, source_id=source.id, kind=models.ArtifactKind.TEXT) is not None
    if has_text and not rows.has_pending_job(db, source=source, kind=models.JobKind.ANALYZE):
        pipeline.set_processing(db, source=source, status=models.ProcessingStatus.PROCESSING)
        pipeline.enqueue_steps(db, source=source, steps=[models.JobKind.ANALYZE])
    return None


def request_news_quiz(db: orm.Session, *, user: models.User, payload: dict[str, object]) -> str | None:
    """Queue this week's news quiz once, and only when a brief was Done in the last 7 days.

    Applied either way: the phone asks on every Sunday Today open, so "already made" and "nothing to quiz" are answers,
    not errors.
    """
    parsed = rows.parse(_NewsQuizPayload, payload)
    if parsed is None:
        return rows.MALFORMED
    week_start = parsed.week_start.isoformat()
    if _quiz_requested(db, user_id=user.id, week_start=week_start):
        return None
    if not card_rows.recently_done_briefs(db, user_id=user.id):
        return None

    jobs.enqueue(
        db,
        kind=models.JobKind.NEWS_QUIZ,
        user_id=user.id,
        payload={briefs.USER_ID_KEY: user.id, card_rows.WEEK_START_KEY: week_start},
    )
    return None


def _is_review_of(db: orm.Session, *, review_id: uuid.UUID, card: models.Card) -> bool:
    review = db.get(models.Review, review_id)
    return review is not None and review.card_id == card.id


def _write_state(card: models.Card, *, state: _FsrsStatePayload) -> None:
    card.fsrs_state = state.fsrs_state.value
    card.stability = state.stability
    card.difficulty = state.difficulty
    card.due_at = state.due_at
    card.last_review_at = state.last_review_at
    card.reps = state.reps
    card.lapses = state.lapses
    card.updated_at = sqlalchemy.func.now()
    card.change_seq = changes.next_change_seq()


def _quiz_requested(db: orm.Session, *, user_id: int, week_start: str) -> bool:
    """Whether a news quiz for this week is queued, running or done; a failed one may be asked for again."""
    requested = db.scalar(
        sqlalchemy.select(
            sqlalchemy.exists().where(
                models.Job.kind == models.JobKind.NEWS_QUIZ.value,
                models.Job.user_id == user_id,
                models.Job.status != models.JobStatus.FAILED.value,
                models.Job.payload[card_rows.WEEK_START_KEY].astext == week_start,
            )
        )
    )
    return bool(requested)
```

```python
def _transcribe(engine: sqlalchemy.Engine, *, audio: bytes, keys: _SpeechKeys, prompt: str, context: llm.CallContext,
                audio_seconds: Decimal) -> str:
    """Groq Whisper first; OpenAI when Groq refuses, fails or isn't configured. Each answered call is recorded."""
    if keys.groq is not None:
        groq_text = _groq_text(audio=audio, api_key=keys.groq, prompt=prompt)
        if groq_text is not None:
            llm.record_audio_call(engine, context=context, provider=models.TranscriptProvider.GROQ,
                                  model=llm.GROQ_WHISPER, audio_seconds=audio_seconds)
            return groq_text
    if keys.openai is None:
        raise fastapi.HTTPException(status_code=502, detail="transcription failed")

    response = speech.post_openai(audio=audio, filename=_AUDIO_FILENAME, media_type=_AUDIO_MEDIA_TYPE,
                                  api_key=keys.openai, prompt=prompt)
    if not response.is_success:
        raise fastapi.HTTPException(status_code=502, detail="transcription failed")
    llm.record_audio_call(engine, context=context, provider=models.TranscriptProvider.OPENAI,
                          model=llm.OPENAI_TRANSCRIBE, audio_seconds=audio_seconds)
    return str(response.json()["text"]).strip()
```

```python
_FOUNDATION_CARDS_PATTERN = re.compile(r"<foundation_cards>(?P<cards>.*?)</foundation_cards>\s*\Z", re.DOTALL)
_FOUNDATION_CARDS = pydantic.TypeAdapter(list[FoundationCard])


def split_primer_output(text: str) -> PrimerOutput:
    """The primer's markdown and the foundation cards written after it.

    A primer without the block (older recordings, or a model that left it out) keeps its text whole and has no cards;
    a malformed block costs the cards, never the primer.
    """
    match = _FOUNDATION_CARDS_PATTERN.search(text)
    if match is None:
        return PrimerOutput(markdown=text, foundation_cards=[])

    markdown = text[: match.start()].rstrip()
    try:
        cards = _FOUNDATION_CARDS.validate_json(match.group("cards"))
    except pydantic.ValidationError:
        _logger.warning("Dropped a malformed foundation cards block")
        return PrimerOutput(markdown=markdown, foundation_cards=[])
    return PrimerOutput(markdown=markdown, foundation_cards=cards[:MAX_FOUNDATION_CARDS])


def preferences_block(notes: Sequence[card_rows.PreferenceNote]) -> str:
    """The user's latest card preferences as a block appended to a card-writing step's message; "" when there are none."""
    if not notes:
        return ""

    lines = [
        f"- cares about: {note.note}"
        if note.kind == models.CardPreferenceKind.CARE
        else f"- doesn't want cards like: {note.note}"
        for note in notes
    ]
    joined = "\n".join(lines)
    return (
        "\n\n<card_preferences>\nWhat the user told Archie about earlier review cards; follow it when writing cards:\n"
        f"{joined}\n</card_preferences>"
    )
```
